# Reminders

## About
This is a programmatic UIKit iOS app that allows users to add reminders into a list of reminders, and also edit each reminder by tapping on it

## Tech Stack
- UIKit
- XCode

## Features
- List of reminders in a TableView
- Plus bar button allowing users to add reminder
- Tapping on a reminder takes you to an edit screen to change that reminder
